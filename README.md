# hansstudy/.github

Default community health files (security policy, contributing guide, code of conduct, issue and
pull request templates) for repositories under [github.com/hansstudy](https://github.com/hansstudy).
A repository that carries its own copy of one of these files uses that copy instead.

Tools and docs: [hans.study/tools](https://hans.study/tools/). Security contact: bugs@hans.study.
